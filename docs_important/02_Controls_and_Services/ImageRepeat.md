# ImageRepeat

**Inherits:** `Enum`

How to paint any portions of a box not covered by an image.

## Properties

| Property | Value | Description |
| --- | --- | --- |
| **`NO_REPEAT`** | `'noRepeat'` | Leave uncovered portions of the box transparent. |
| **`REPEAT`** | `'repeat'` | Repeat the image in both the x and y directions until the box is filled. |
| **`REPEAT_X`** | `'repeatX'` | Repeat the image in the x direction until the box is filled horizontally. |
| **`REPEAT_Y`** | `'repeatY'` | Repeat the image in the y direction until the box is filled vertically. |
